## 自行重拍／公開後擷取
1. 用較新瀏覽器開啟 index.html 或已公開的 Pages 網址。若已有自己需要的紀錄，不要為截圖清除它們，可用獨立瀏覽器設定檔。
2. 設定 30 分鐘、0 元、室內，抽一個任務；截下頁首、條件與完整卡片。
3. 接受並按「開始倒數」，截下任務名稱、倒數與暫停／提前完成操作。
4. 用 DevTools 的裝置工具列設定 375px 寬度，或使用實體手機，截下單欄與主要操作。
5. 用瀏覽器截圖功能、Windows 剪取工具或手機截圖保存 PNG；若使用測試完成紀錄，在作業圖說標「測試展示資料」。

若課堂要求網址列也出現在圖片中，請用剪取工具連同真正網址列一起擷取。本次交付為網站畫面，未包含瀏覽器網址列。
